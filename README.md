# TAKAWALA (টাকা ওয়ালা) - Earning App

A modern, responsive, and feature-rich Bengali micro-task, rewards, and earning platform built with React, Vite, TypeScript, and Tailwind CSS.

## Features

- **Authentication & Security**:
  - Sign in, Registration with referral codes, password reset, 1-click instant demo test login.
  - 4-digit transaction security PIN protection for withdrawals.

- **Dashboard & Earnings**:
  - BDT (৳) and USDT ($) currency toggle.
  - Daily task goal progress tracking with animated progress bars.
  - 3D Spherical floating widgets: "Happy Hour" 10% discount multiplier & "Mystery Gift" daily surprise boxes.
  - Marquee announcement ticker.
  - Account Activation Banner.

- **Earning Channels**:
  - **Free & VIP Tasks**: Sponsored micro-tasks (YouTube, Telegram, Facebook, surveys, app reviews) with countdown timers and proof submission.
  - **Interactive Spin Wheel**: 8-segment canvas lucky wheel with realistic easing physics and sound/confetti rewards.
  - **Lucky Draw Lottery**: Daily ৳5,000 jackpot draw, ticket purchasing, and automated draw verification.
  - **Quiz Contest**: 4 categories (সাধারণ জ্ঞান, গণিত, বিজ্ঞান, ইসলামিক) with 60-second timed challenges and instant payouts.
  - **Watch & Earn**: Sponsored video ad viewer with daily quotas.
  - **Gmail Creation Tasks**: Micro-job tasks for verified email account creation.
  - **Job Post Marketplace**: Create custom campaigns with worker budget calculators.
  - **Promo Codes**: Instant redeem voucher coupons (`TAKA100`, `BONUS50`, `WELCOME20`, `VIP2026`).

- **Wallet & Transactions**:
  - 3 Dedicated balances: Earning / Income, Deposit, and Mobile Recharge.
  - Cash-in Deposit via bKash, Nagad, Rocket, and Binance USDT (TRC-20) with 1-click account number copying.
  - Cash-out Withdrawal with live 10% VAT deduction calculation and PIN authentication.
  - Mobile Top-up for all Bangladeshi operators (GP, BL, Robi, Airtel, Teletalk).
  - Internal wallet transfer between balances and peer-to-peer user transfer.
  - Authentic wide-format digital receipts with TrxID copying and verification seal.

- **VIP Memberships**:
  - Silver VIP (৳150), Gold VIP (৳350), Platinum VIP (৳750) with 1.5x - 3.5x income multipliers and express withdrawal privileges.

- **Support & AI Assistant**:
  - **TWAI Chatbot**: Dedicated virtual AI assistant with 40+ comprehensive Bengali FAQ answers, quick query chips, and free-text question answering.
  - 24/7 Live Support via Telegram channel, Telegram admin chat, WhatsApp, and in-app support tickets.

## Tech Stack

- **Framework**: React 19 + TypeScript + Vite 6
- **Styling**: Tailwind CSS v4 + Remix Icons
- **Effects**: Canvas Confetti, CSS 3D spherical transforms, frosted glassmorphism
